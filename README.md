# BOOMBOX KIDS™ Prompt Studio

BOOMBOX KIDS™ is a browser-based creative prompt studio for original kids-apparel concepts, coordinated outfits, collections, and production-minded sizing guidance.

## Use the app

Open the public app: **[Launch BOOMBOX KIDS™ Prompt Studio](https://sweetrose37.github.io/boombox-kids-generator/)**

The finished product created by this application is a production prompt. It does not generate images, place print orders, or connect to a printer.

## Local development

Requires Node.js 24 LTS or newer.

```powershell
npm start
```

Then open `http://127.0.0.1:4173/`.

## Validation

```powershell
npm test
npm run check
```
